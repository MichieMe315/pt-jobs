## Anchor Text Guidelines

### Recommended Patterns

1. **Exact Match** (use sparingly)
   - "physiotherapy jobs in British Columbia"
   - "physiotherapist positions in Vancouver"

2. **Partial Match** (recommended)
   - "career opportunities in BC"
   - "physiotherapy work in Victoria"

3. **Branded** (balanced)
   - "BC physiotherapy positions"
   - "current job openings"

4. **Natural/Generic** (use where appropriate)
   - "view all positions"
   - "explore career options"
   - "learn more about working in BC"

### Avoid

- Exact match anchor text for every link (appears unnatural)
- Generic "click here" text
- Over-optimized commercial terms

## Monitoring and Maintenance

### Quarterly Review

1. **Check for broken links**
   - Use automated tools to identify 404 errors
   - Fix or redirect broken internal links

2. **Analyze link distribution**
   - Ensure new pages receive appropriate internal links
   - Rebalance if certain pages have too few connections

3. **Update anchor text**
   - Ensure anchor text remains relevant
   - Avoid repeated exact match anchors

4. **Content freshness**
   - Update links to reflect new content
   - Remove links to deprecated pages

---

## Implementation Notes

### When Creating New Content

1. Identify 2-4 relevant internal link opportunities
2. Use natural, varied anchor text
3. Links should provide genuine value to readers
4. Place links within relevant context, not forced

### When Updating Existing Content

1. Check for broken links
2. Add links to new content where appropriate
3. Ensure anchor text remains accurate
4. Remove links to deprecated or irrelevant content

---

## Summary

A well-structured internal linking strategy supports both user experience and search engine visibility. Focus on:

- Logical content hub structure
- Natural, varied anchor text
- Consistent linking from related content
- Regular monitoring and maintenance

Remember: Internal linking should serve users first, search engines second. Prioritize helpful connections over mechanical optimization.
